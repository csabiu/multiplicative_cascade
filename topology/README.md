# topology

Exact topology of the conservative (random-permutation) cascade generated by `multifrac.py`.

- `cascade_genus.py`: ensemble-mean digital Euler density of the 2D level-`J` excursion set
  `{rho > nu}` under the (4,8) convention (4-connected foreground), `chi/A = p1 - pEh - pEv + pF`,
  as an exact finite recursion over the multinomial atoms. Also the matching measurement on
  simulated fields, the finite-grid conversion, and an exhaustive `J=2` enumeration
  (`python cascade_genus.py`).
- `cascade_genus_3d.py`: the 3D analogue under the (6,26) convention,
  `chi/V = p1 - 3 pE + 3 pF - pC`.

```python
import sys; sys.path.insert(0, 'topology')
from cascade_genus import GenusTheory, genus_theory, genus_measured
th  = GenusTheory([0.42, 0.30, 0.20, 0.08], J=8)   # J = depth: 2^J cells per side
thr = th.gap_thresholds(n_max=60)                  # ln(nu) thresholds between atoms
A   = genus_theory([0.42, 0.30, 0.20, 0.08], 8, thr)        # p1, pE, pF, chi (bulk densities)
M   = genus_measured([0.42, 0.30, 0.20, 0.08], 8, thr, nreal=1200)   # mean and s.e. from multifrac
```

Conventions: `J` counts the first subdivision, so `multifrac(..., levels=J-1)` makes the same field.
`p1` is identical in every realization (fixed multiset); `pE`, `pF`, `chi` agree with simulation
within sampling error. The bulk density normalizes each count by its own number of
configurations; `finite_grid_chi` gives the expected finite-grid count per cell.

Reference: C. G. Sabiu, *Exact topology of conservative multiplicative cascades: an ultrametric
transfer-operator genus*, J. Phys. A (in review).
